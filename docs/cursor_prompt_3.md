# Cursor Prompt #3: MuMax3 Integration

You are adding a real MuMax3 integration boundary for SpinVault Twin. Your job is to translate validated micromagnetic request parameters into auditable MuMax3 job artifacts and execute MuMax3 only when the binary/environment is actually configured.

## Objective

Implement a MuMax3 adapter that can:

- Check whether MuMax3 is installed/configured.
- Generate a transparent `.mx3` script from validated request fields.
- Save input, script, logs, and outputs in a job folder.
- Execute MuMax3 only when explicitly available.
- Parse basic output metadata without overstating scientific interpretation.

## Scientific Boundary

Do not invent missing MuMax3 commands. Do not translate parameters unless their mapping is explicit in the code and documented. When uncertain, leave the field unsupported and return a validation warning.

Do not claim the model is calibrated or physically validated. The adapter only runs a numerical solver with user-provided/request-provided parameters.

## Configuration

Use environment variables:

```text
MUMAX3_BINARY=/path/to/mumax3
SPINVAULT_JOB_ROOT=/path/to/jobs
MUMAX3_TIMEOUT_SECONDS=600
```

If `MUMAX3_BINARY` is absent or not executable, requests should return:

```json
{
  "status": "not_configured",
  "error": "MuMax3 binary is not configured on this machine."
}
```

## Adapter Interface

```py
class Mumax3Adapter:
    def is_available(self) -> bool: ...
    def prepare(self, request: SimulationRequest) -> PreparedMumaxJob: ...
    def run(self, prepared: PreparedMumaxJob) -> SolverRunResult: ...
    def parse_outputs(self, job_dir: Path) -> SimulationResult: ...
```

## Script Generation

Generate a `.mx3` file from supported fields only. Add comments for every input source.

Example shape:

```go
// Generated by SpinVault Twin
// Scenario: {scenario_id}
// This script reflects user-provided parameters and is not a validated device model.

SetGridSize(nx, ny, nz)
SetCellSize(dx, dy, dz)

Msat = ...
Aex = ...
alpha = ...

m = uniform(mx, my, mz)

run(total_time)
tablesave()
```

Replace placeholders only when values are present and valid.

## Unit Handling

Convert frontend/backend quantities to SI units before script generation. Keep conversion logic tested and explicit.

```py
def to_si(quantity: Quantity) -> float:
    ...
```

Reject unknown or unsupported units.

## Input Validation

Before generating a script, validate:

- Mesh cell size and grid size are present.
- Magnetic material fields required by the selected MuMax3 mode are present.
- Simulation time is positive.
- Initial magnetization is valid.
- Current density is present only for modes that support it.

Return structured warnings for unused fields.

## Execution

Use subprocess safely:

- No shell interpolation.
- Pass arguments as a list.
- Set timeout.
- Capture stdout/stderr.
- Persist logs.
- Mark failed jobs clearly.

## Outputs

Store:

```text
job_dir/
  request.json
  generated.mx3
  stdout.log
  stderr.log
  outputs/
  result.json
```

Parse only outputs that exist. If table data is available, expose it as raw series with labels and units. Do not infer switching behavior or device performance unless implemented explicitly and documented.

## Provenance

Each result must include:

- solver: `"mumax3"`
- solver version if available
- generated script hash
- request hash
- start/end timestamps
- warnings
- logs path or artifact references

## Frontend Contract

The frontend should show:

- MuMax3 configured/not configured
- Job status
- Script preview/download
- Logs
- Raw table outputs
- Warnings about model validation status

## Tests

Add tests for:

- Availability check
- Unit conversion
- Script generation from a minimal valid request
- Missing required fields
- Unsupported units
- Subprocess failure handling
- Timeout handling if practical

Mock actual MuMax3 execution unless CI has a known binary.
